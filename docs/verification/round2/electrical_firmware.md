**Firmware items checked and found correct**
- **CG encoding** (TLC59116 §9.5.9: VG = (1+HC)(1+D/64)/4, CG = VG·3^(CM−1)): 0x7F = 0.3307 (CM=0, 8.3 mA, inside 5–40 mA); 0xBF = 0.4961 (12.5 mA, inside 10–120 mA); 0xFF = 0.9922 (25.0 mA).
- **Write ordering:** gain up writes PWM first, gain down writes IREF first. The in-between state is never brighter than either end.
- **Auto-increment:** AI = 100 is used only for block writes within 00h–1Bh; IREF at 1Ch is written alone with AI = 000.
- **MODE1 and timing:** the MODE1 mask 0x11 matches the POR default (OSC = 1, ALLCALL = 1; AI bits are read-only). The 600 µs oscillator wait covers the 500 µs maximum.
- **LM75B:** Conf 0x08 = queue 2, active low, comparator, normal (Table 8). Tos 60 → 0x3C00 and Thyst 52 → 0x3400 match the 9-bit left-aligned format (Tables 11–13). Temp is read as 11 bits with an arithmetic shift.
- **Watchdog:** WDT 2KCLK = 2.05 s and the PIT = 1 s (same OSCULP32K). The worst loop path, the power-cycle, is about 0.52 s plus I²C timeouts. megaTinyCore 2.6.11 Wire has `TWI_TIMEOUT_ENABLE` by default (`Wire.h:134`), so a stuck bus cannot hang it.
- **Pins and sleep:** megaTinyCore `pinMode()` keeps the ISC bits, so INPUT_DISABLE survives `pinMode(INPUT)` (`wiring_digital.c`). The RTC is enabled before the PIT, and TCD0 drives millis, so there is no RTC conflict.
- **Timer and integer arithmetic:** every timer comparison is elapsed-time and wrap-safe. No integer overflow at real VDD values.
- **Build configuration:** the fault-injection flags exist only in the `bench_*` envs, and `default_envs` is the release env. `upload` does not write fuses (platform `main.py`), so the FW-09 process step is needed.
