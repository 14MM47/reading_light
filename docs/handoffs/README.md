# Handoffs for Claude Code in VS Code (Matt's laptop)

Each handoff is a self-contained task for a local Claude Code session (VS Code), where a human is present and
local tools/hardware exist. Do them in order; tick the "Done when" of each.

| # | Handoff | Needs |
|---|---|---|
| 01 | [PCB final review and order](01-pcb-order.md) | KiCad 9 GUI, fab websites (Matt pays) |
| 02 | [Parts order (Farnell + others)](02-parts-order.md) | browser (Matt pays) |
| 03 | [3D printing (Bambu X2D)](03-printing.md) | Bambu Studio / 14MM47/3dprint pipeline, printer |
| 04 | [Firmware build and flashing](04-firmware.md) | PlatformIO, UPDI programmer |
| 05 | [Assembly and bring-up tests](05-assembly-bringup.md) | soldering kit, multimeter, bench supply optional |
| 06 | [Thingiverse survey](06-thingiverse-survey.md) | browser |

Standing rules for all of them: never place an order or start a print without Matt; follow `CLAUDE.md`; record
measurements in `docs/verification/VERIFY.md` and decisions in `PLAN.md`.
